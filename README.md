# Net Worth Navigator

Track your assets, liabilities, and net worth — and see how your actual investments stack up against a plain savings account.

## Features
- Assets / Liabilities / Net Worth snapshot
- 10-year projection charts (assets vs liabilities + net worth)
- **Bank-only vs Actually Invested** comparison — quantifies your "investing alpha"
- Add/remove rows for any asset or liability type
- Loan amortization with EMI for liability balances
- Persists in browser `localStorage`
- Smart suggestions panel

## Run
```bash
npm install
npm run dev
```

## Deploy
Pre-configured for Netlify (`netlify.toml`) and Vercel (`vercel.json`).
- `npm run build` → output in `dist/`
